    How it works

    Every 10 minutes the bike count of every YouBike station in Taipei and New Taipei is saved, with the weather. A machine-learning model trained on that history predicts how many bikes each station will have one hour later.

    • Bikes available: 6 or more bikes expected
    • Only a few bikes: 3 to 5 bikes expected
    • No bikes soon: 2 or fewer bikes expected
    • No parking soon: 2 or fewer free docks expected

    The model looks at the bikes there now, how that changed in the last hour, the same time yesterday, nearby stations, the time of day, the location and the weather forecast.

    Data collection started on 30 Oct 2026, so the model has only seen a few days. Treat forecasts as a helpful estimate, not a guarantee.
